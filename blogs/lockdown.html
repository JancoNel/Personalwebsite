Lockdown: How I Built My Automated Threat Response Tool

Posted: 2025-07-18

While experimenting with Aurora Lite, I discovered it could execute custom actions and scripts when something suspicious was detected. That sparked a creative idea — what if I could make it run any code on detection? Suddenly, I had full control over how a system could respond when it was under threat.

That led me to build Lockdown — a standalone Python-based response tool designed to react immediately and aggressively to signs of compromise. It can run either as a script or a compiled binary and is built for anyone who doesn’t want to rely on full-blown commercial EDR/XDR setups. It works as a plug-and-play defensive measure.

One of the first features I implemented was forensic collection and instant alerting via Discord webhooks. Discord is a great poor man's info server — it gets the job done when you just need alerts without the overhead of a full logging system. I wanted to be pinged *immediately* if anything went wrong, even if I was hanging out with the boys.

Funny enough, the idea of cutting the internet connection before doing anything came to me in a dream. I don't remember the details anymore, but I woke up with the concept clearly in mind — isolate first, investigate second. That ended up being one of Lockdown's core behaviors.

🔧 How It Works

Here's the sequence Lockdown follows when triggered:

  • 🔒 Instantly blocks all network connections to stop data exfiltration and command & control channels.
  • 🧹 Terminates dangerous or suspicious processes
  • 📦 Collects forensic data about running processes, user info, and host metadata.
  • 📡 Temporarily restores the internet to send an alert and forensic dump via a Discord webhook.
  • 💥 Immediately shuts down the system to prevent further exploitation.
  • ⚙️ Designed for integration with EDR/XDR tools as a post-detection response module.

It's quick, brutal, and designed to make sure the attacker can't do anything meaningful once caught.

Originally, I named the project Red Alert to reflect how serious a breach is, but someone suggested Lockdown — and that just clicked. It felt tighter and more intentional, so I ran with it.
